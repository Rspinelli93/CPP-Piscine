# 42 C++ Piscine: Discovery of OOP

A collection of exercises from the 42 Network C++ Piscine, focusing on the transition from C to C++ and the core principles of Object-Oriented Programming.

## 📂 Modules Overview

| Module | Focus | Key Concepts |
| :--- | :--- | :--- |
| **CPP 00** | Basics & Syntax | Namespaces, Classes, Member functions, I/O streams |
| **CPP 01** | Memory & Pointers | Memory allocation, Pointers to members, References |
| **CPP 02** | Ad-hoc Polymorphism | Fixed-point numbers, Operator overloading, Orthodox Canonical Form |
| **CPP 03** | Inheritance | Base/Derived classes, Access specifiers, Chained constructors |
| **CPP 04** | Subtype Polymorphism | Virtual functions, Abstract classes, Interfaces, Deep vs Shallow copies |
